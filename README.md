# Nova Keys
Offline Android keyboard by **Zayd** — English QWERTY + Avro-style phonetic Bengali.

Features: 3 matte themes (Chalk / Graphite / AMOLED), popup key bubbles, number row toggle,
long-press digits, haptics with adjustable strength, adjustable height, Bengali candidate bar,
no INTERNET permission, no analytics. All code is original (not derived from any other keyboard).

Build: open this folder in Android Studio (JDK 17, SDK 34) and Run, or `gradle assembleDebug`.
Then: open app -> Enable keyboard -> Switch to Nova Keys. Tap "EN" to toggle "বাং".
Not included yet: glide typing, word prediction for English.
